Wearable IMU Glove

A six-IMU glove for measuring finger range of motion in clinical hand-function assessment. I built the Python pipeline that turns raw sensor quaternions into joint angles, and a PCA method that finds the axis each finger actually rotates about instead of trusting how the sensor happens to sit on the hand.

Research in progress. Code is not public yet.

How it works

The problem

An IMU strapped to a finger never lines up perfectly with the joint. Measuring rotation about the sensor's own axis underestimates how far the finger really bends.

PCA on quaternions

During each movement the finger rotates mostly about one direction. PCA on the quaternion data recovers that functional axis for every finger and participant.

Pipeline at scale

A Python pipeline processes 15,000+ recordings from human participants into per-finger range-of-motion values ready for clinical analysis.

Fewer sensors

Because the axis is learned from data, the glove captures on average 98% of finger motion with fewer sensors than comparable designs.
