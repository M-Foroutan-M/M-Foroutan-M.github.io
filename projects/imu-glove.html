Wearable IMU Glove

A glove with six inertial sensors (IMUs) for measuring finger range of motion in clinical hand-function assessment. I built the Python pipeline that turns raw sensor quaternions into finger angles across more than 15,000 recordings from human participants. I also designed a PCA-based method that finds the axis each finger actually bends around, so the glove captures 98% of finger motion on average with fewer sensors than comparable gloves.

Research in progress. Code and data are not public yet.
The method

Find the axis the finger really bends around

An IMU strapped to a finger never lines up perfectly with the joint. If you measure rotation about the sensor's own axis, you miss part of the movement, and the error changes from person to person and every time the glove is put on.

During a movement, though, each finger rotates mostly about one direction. Running PCA on the quaternion data recovers that functional rotation axis for every finger and every participant, so the angle is measured about the axis the finger actually uses.

Pipeline

From raw recordings to clinical numbers

The Python pipeline reads the quaternion streams from all six IMUs and works out each finger's functional axis and angle over time. It then reports a range-of-motion value per finger, ready for clinical analysis.

It runs across a dataset of more than 15,000 hand-function recordings from human participants. Because the axis comes from the data rather than from where the sensor sits, the glove captures on average 98% of finger motion while using fewer sensors than comparable gloves.
