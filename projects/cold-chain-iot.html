Cold-Chain Sensor Hub

An always-on edge computer for refrigerated delivery vans. It reads nine sensors, logs structured telemetry every 5 seconds and pushes it to the cloud over 4G every 30 seconds. It keeps working through signal loss and restarts itself after a crash or power cut.

/how

How it works

Many buses, one pipeline

I2C, 1-Wire, UART, GPIO and RS485 Modbus sensors feed a single config-driven Python pipeline. Adding a sensor means editing a config file, not the core code.

Offline first

Data is written locally first and uploaded with rclone over a SIM7600 4G modem, so nothing is lost when the van drives through a dead zone.

Zero-touch operation

Runs as a systemd service with auto-start, crash recovery and self-healing, so the driver never has to touch it.

Ready for analysis

I contributed to the SQL schema that archives sensor and route data for the companion web platform.
